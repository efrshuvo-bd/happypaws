# HappyPets — Pet Routine & Medication Tracker 🐾💊

**HappyPets** is a proprietary Android application built with **Jetpack Compose** and **Material 3**. It offers cat and dog owners a comprehensive daily care checklist, multi-phase tapering medication schedules, health metric tracking, household caregiver syncing, and an offline Emergency Vet Pass.

---

## Technical Stack & Architecture

* **UI:** Jetpack Compose (Material 3 Adaptive Layouts for phones, foldables, and tablets)
* **Architecture:** Clean Architecture + MVVM (Unidirectional Data Flow)
* **Async & Reactive:** Kotlin Coroutines + Flow
* **Local Storage:** Encrypted Room Database
* **Widgets:** Jetpack Glance (Home Screen & Lock Screen integration)
